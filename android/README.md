# SpotDL Android

Αυτόνομη Android έκδοση του SpotDL GUI Pro. Δεν απαιτεί υπολογιστή ή server.

## Λειτουργίες

- Spotify album και track links μέσω της δημόσιας embed σελίδας.
- Απευθείας media links που υποστηρίζει το ενσωματωμένο `yt-dlp`.
- Μετατροπή σε MP3 μέσω του ενσωματωμένου `ffmpeg`.
- Αυτόματη ενημέρωση του `yt-dlp` από το nightly channel, ενεργοποίηση του νεότερου EJS challenge solver και διαδοχικές εναλλακτικές συνδέσεις όταν το YouTube απορρίπτει μία λήψη με HTTP 403.
- Τρεις επιλογές ποιότητας MP3.
- Μόνιμη επιλογή φακέλου λήψεων μέσω του Android system picker, με δυνατότητα επιστροφής στον προεπιλεγμένο φάκελο.
- Σταθερά ονόματα αρχείων από τα στοιχεία Spotify, συνέχιση μετά από μεμονωμένη αποτυχία και αυτόματη δεύτερη προσπάθεια στα κομμάτια που απέτυχαν.
- Foreground λήψη με ειδοποίηση και δυνατότητα ακύρωσης.
- Αυτόματος έλεγχος νέων εκδόσεων σε κάθε εκκίνηση από τα GitHub Releases του `chkontog2026/spotdl-android`.
- Αυτόματη λήψη, έλεγχος SHA-256/ψηφιακής υπογραφής και ασφαλής παράδοση του APK στον Android installer.
- Λήψη links μέσω του Android Share menu.
- Αποθήκευση στο `Downloads/SpotDL Android` και ενημέρωση της βιβλιοθήκης πολυμέσων.

## Build

Από τον κεντρικό φάκελο του project:

```powershell
.\build_android.bat
```

Το προτεινόμενο APK για σύγχρονα κινητά δημιουργείται ως `android-releases\SpotDL_Android_ARM64_v1.1.6.apk`.
Δημιουργείται επίσης universal APK ως `android-releases\SpotDL_Android_Universal_v1.1.6.apk`, το οποίο είναι σημαντικά μεγαλύτερο επειδή περιλαμβάνει όλες τις αρχιτεκτονικές επεξεργαστή.

Οι ενημερώσεις εγκαθίστανται μόνο όταν το APK έχει το ίδιο package name και την ίδια ψηφιακή υπογραφή με την ήδη εγκατεστημένη εφαρμογή. Το Android ζητά πάντα τελική επιβεβαίωση από τον χρήστη.

Η πρώτη εκτέλεση χρειάζεται internet για να ληφθούν οι Gradle/Maven εξαρτήσεις. Το παραγόμενο APK περιλαμβάνει τη μηχανή Python, `yt-dlp` και `ffmpeg`.

## Σημείωση

Η αντιστοίχιση Spotify τίτλων γίνεται με δημόσια διαθέσιμα αποτελέσματα αναζήτησης. Για αυτό μπορεί περιστασιακά να επιλεγεί λάθος έκδοση ενός τραγουδιού. Η εφαρμογή προορίζεται αποκλειστικά για περιεχόμενο που ο χρήστης έχει δικαίωμα να κατεβάσει.
